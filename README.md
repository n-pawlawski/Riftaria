# Riftaria

A **Terraria** mod built on **tModLoader 1.4.4**.

Riftaria replaces the open world with a hub-and-runs loop:

1. You live in **the Hold**, a small sealed hub.
2. A **Rift Gate** opens an instanced pocket world, generated fresh every time, at any tier you have unlocked.
3. Enemies come from **destructible spawners** rather than ambient spawning. You fight along the layout to the far end.
4. A boss holds the far end. Killing it unlocks the next tier and sends you home with the loot.

There are **ten tiers**, one per section of the vanilla game, from pre-boss through Moon Lord. Loot comes from chests, enemy drops and the boss, and vanilla drop tables are replaced rather than extended.

**Blocks cannot be mined or placed**, in the Hold as well as in rifts, beyond a small whitelist. The generated layout is the level, and gear comes from rifts rather than ore.

## Status

**Working towards a first playable**, scoped on the Miro board and recorded in [docs/design-decisions.md](docs/design-decisions.md). The target is the smallest build that proves the loop: the Hold generates, a Rift Gate opens a rift, one thing in it dies, and you come back with the next tier unlocked.

The prototype has been cut back to match that scope. Rift Sigils, the XP curve, the stat tree, the stat panel and the experience bar are gone — they implemented decisions that have since been reversed. Two knowingly temporary things remain: the **Rift Warden** stands in for a real boss until Boss Adapters exist, and enemies still use vanilla-style spawning rather than spawners.

**It has never been compiled.** Written on a machine with neither Terraria nor the .NET SDK, so the first in-game build should be treated as a debugging session rather than a smoke test.

Written:

- Mod skeleton, `build.txt` with the SubworldLibrary dependency, localization, placeholder sprites
- Hub world generation — vanilla passes disabled, a sealed Hold built from scratch
- Rift subworld, seed pass, and the room-and-corridor layout generator
- Tier table and run state, with tier access derived from what the Hold has cleared
- Mining, placement, explosion and gravestone lockdown, with per-tile whitelists
- Rift Gate tile and item, and the Gate panel that lists tiers
- Rift enemies, the placeholder Rift Warden, spawn control, and clear detection
- `/rift` developer commands

Not written, and nothing references it:

- Spawners. Encounters still use vanilla-style spawning with a filtered pool.
- Boss Adapters, and the nine tiers past the third.
- Loot of any kind. Clearing a tier unlocks the next and pays nothing else.
- `Mod.HandlePacket`. Run completion sends a packet that nothing receives; every send site is behind a `netMode` check, so single player is unaffected.
- `docs/build-and-test.md` — the first-build checklist.

## Requirements

- Terraria (Steam) and tModLoader **1.4.4-stable**
- .NET 8 SDK (x64) — not 9 or 10
- [Subworld Library](https://steamcommunity.com/workshop/filedetails/?id=2785100219) — a hard dependency; rifts are subworlds

## Running it

1. Subscribe to Subworld Library on the Steam Workshop.
2. Copy or symlink the `Riftaria/` folder in this repo into your tModLoader `ModSources` directory:
   - Windows: `Documents\My Games\Terraria\tModLoader\ModSources\Riftaria`
   - Linux: `~/.local/share/Terraria/tModLoader/ModSources/Riftaria`
   - macOS: `~/Library/Application Support/Terraria/tModLoader/ModSources/Riftaria`
3. In tModLoader: **Workshop → Develop Mods → Riftaria → Build + Reload**.
4. Create a new world. Worldgen is replaced wholesale, so an existing world will not work.

For IDE IntelliSense, drop `SubworldLibrary.dll` and `SubworldLibrary.xml` into `Riftaria/lib/`. The `.csproj` picks them up if present and ignores them if not; tModLoader itself resolves the reference from `modReferences` in `build.txt`.

### Placeholder art

Every sprite in the repo is a flat-colour placeholder generated by a script, because tModLoader will not load content whose texture is missing. To regenerate:

```bash
python3 tools/make_placeholder_sprites.py --force
```

Delete a placeholder and drop in real art of the same dimensions to replace it. Frame counts are documented in the script.

## Developer commands

Typed in chat:

| Command | Effect |
| --- | --- |
| `/rift enter <tier>` | Open a rift, ignoring whether it is unlocked |
| `/rift exit` | Return to the Hold |
| `/rift clear <tier>` | Mark a tier cleared, unlocking the next |
| `/rift reset` | Forget all progress; only tier 1 stays open |
| `/rift tiers` | Report how many tiers exist and which are open |
| `/rift where` | Report the current world |
